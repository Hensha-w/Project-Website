##  Features

### User Features
-  User authentication (register/login)
-  Create and manage final year projects
-  View admin-proposed pricing and descriptions
-  Accept or contest project pricing
-  Secure payment system with receipt upload
-  Contact developer via provided phone number
-  Dashboard for project status tracking

### Admin Features
-  Review submitted projects
-  Set project pricing with descriptions
-  Approve/Reject payments
-  Provide contact information to users
-  Manage project negotiations

## 🛠 Tech Stack

### Backend
- **Node.js** - Runtime environment
- **Express** - Web framework
- **MongoDB** - Database
- **Mongoose** - ODM for MongoDB
- **JWT** - Authentication
- **Multer** - File uploads
- **bcryptjs** - Password hashing

### Frontend
- **React** - UI library
- **React Router** - Navigation
- **Material-UI** - Component library
- **Axios** - HTTP client
- **React Hook Form** - Form handling
- **date-fns** - Date utilities

### Development Tools
- **Nodemon** - Server auto-restart
- **Concurrently** - Run multiple commands
- **WebStorm** - IDE

##  Installation

### Prerequisites
- Node.js (v16 or higher)
- MongoDB (v4.4 or higher)
- npm or yarn
